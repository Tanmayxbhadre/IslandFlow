Your Mac. Your Data.

IslandFlow is built local-first. It processes hardware events strictly on your Mac using native macOS APIs. It contains zero analytics, zero ad-tracking, zero remote network calls, and requests only minimum necessary system permissions.

Because IslandFlow is a free open-source utility (ad-hoc signed for local testing), macOS Gatekeeper may show a security warning on initial launch.

Option A (1-Click Installer): Inside the DMG, double-click Install IslandFlow.command to automatically copy to Applications, clear quarantine, and launch.
Option B (Right-Click Open): Right-click IslandFlow.app in Applications → Select Open → Click Open in the security dialog.
